# ⚡ Conversor Universal

Editor y conversor **Markdown/HTML** con estilo futurista 🌌.  
Convierte tu contenido a múltiples formatos directamente desde el navegador.

---

## ✨ Funcionalidades

- 👀 **Previsualización en tiempo real** (Markdown → HTML).
- 📂 **Carga de archivos locales** (`.md`, `.html`, `.txt`).
- 📤 **Exportación a múltiples formatos**:
  - PDF
  - DOCX
  - PNG
  - TXT
  - MD
- 🎨 **Interfaz galáctica** con fondo estrellado y glassmorphism.
- 🚀 **Funciona en GitHub Pages** (no requiere instalación).

---

## 🛠️ Uso

1. Ingresa aquí 👉 [Conversor Universal en línea](https://joh4nn6.github.io/convertidor/)  
2. Escribe o pega tu texto en el panel izquierdo.  
3. Mira la previsualización en el panel derecho.  
4. Usa los botones para exportar al formato que quieras.
